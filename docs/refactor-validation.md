# 重构验收记录

日期：2026-09-23。

## 范围

将原来 1,461 行的 `panel.js` 按设置、内容展示、表格交互、正文读取和 SQL 重放拆分；入口保留请求列表、页签和事件协调。删除始终返回 `true` 的布局判断及失效分支，合并重复的分栏宽度保存逻辑。未添加第三方依赖，未修改页面 HTML、CSS、图标、manifest、权限和默认配置。

## 已修复问题

- 异步正文返回后，请求列表的“表”标记未更新。
- 筛选结果为空后清除筛选，详情仍为空。
- 全局搜索点击被列表类型或 URL 筛选隐藏的结果时，选错请求。
- 保存解密配置、切换原始内容后，视图或列表标记仍显示旧结果。
- 清空或导航后，迟到的 HAR 回调重新填入旧请求；Promise 形式的 HAR 失败产生未处理拒绝。
- 空表单字段被替换为 `(binary)`；读取不到正文被误报为空响应。
- `application/*+json`、`application/*+xml` 被当作二进制或文件，无法正确展示。
- 响应搜索不能跨 JSON 高亮节点匹配完整字段表达式。
- 恢复默认设置后，旧分栏宽度仍生效。
- 表格缺少 `constructor` 等字段时，读取原型属性作为数据。
- 多个 `isExplain` 参数中后续的 `true` 未被识别。
- SQL 重放的启动异常、轮询失败和迟到回调未完整清理任务；响应头返回后过早取消正文读取超时。
- SQL 重放头过滤误删名称仅以保留头名称开头的自定义头；缺失正文的请求可能被错误重放。
- 本地 `/api/table` 样例没有 SQL 解释分支。
