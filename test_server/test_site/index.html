EXTENSION CHECK

点按钮发请求，在面板里查看结果

先打开本页的开发者工具并选择「牛牛爱上班」，然后运行下面的接口样例。选中任一请求后打开「获取SQL」页签，可测试带原请求参数和本地 mock Cookie 的 SQL 解释流程。

GET原始 JSON

未加密响应

/api/plain?source=button

返回普通 JSON，验证插件不会误解密，并能显示响应内容。

GET对象列表

直接表格数据

/api/table?source=button

直接返回对象列表，不使用 data 包装，验证插件自动识别表格。

GET图片文件

PNG 图片响应

/api/image

返回真实 PNG 二进制内容，验证 Preview 图片展示和 Response 不阻塞。

GETAES 加密

加密响应

/api/encrypted?source=button

返回与插件 extension/crypto.js 密钥匹配的 Base64 密文，解密后是 JSON。

GET部分字段 AES

部分加密响应

/api/partial?source=button

仅 data 是密文；验证插件只解密密文字段并保留普通字段。

POSTBase64 参数/响应

Base64 参数样例

/api/base64?filter=MT0x

Query、嵌套 JSON 和响应中包含 Base64 值，验证解码并保留普通文本。

POST转义参数

Python 风格参数

/api/loose-params

请求体包含 {'tag_id': 'LTE='}，验证无 JSON 双引号时的嵌套 Base64 解码。

POSTHeader + Payload

请求回显

/api/echo?source=button

发送自定义 Header 和 JSON Payload，服务器以普通 JSON 回显；也可用它测试 SQL 请求是否保留 Header、Payload 和本地 mock Cookie。
